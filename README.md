## 🧱 Featured Products & Projects  

### 🧬 **[Generic MCP Server](https://github.com/manishmlv50/postgres-mcp-server)**  
A powerful **Model Context Protocol (MCP)** server that enables conversational interaction with databases using natural language queries. Supports multiple database types **(PostgreSQL, MySQL, SQLite)** and AI providers **(OpenAI, Google Gemini, Anthropic Claude)**.
*Stack:* Node.js • PostgreSQL • Express • TypeScript • REST • JSON API  • MCP • Gemini  

---

### 🧾 **[Docuvery](https://www.docuvery.com/)**  
An intelligent **document-processing and automation platform** that handles templates, PDF generation, and workflow orchestration at scale.  
*Stack:* Node.js • TypeScript • PostgreSQL • Docker • Queue-based Processing  • Distributed Computing 

---

### 📊 **[Atom Stock Options](https://atomstockoptions.com)**  
A modern platform for **stock-options plan design and management** for startups and investors — simplifying cap-tables, vesting, and compliance.  
*Stack:* Node.js • PostgreSQL • Angular • Stripe • AWS ECS & CloudFront  

---

### 🧘 **[Contemplate Life](https://contemplate.life)**  
A **mental-fitness and wellbeing platform** combining AI guidance, journaling, and personalized training programs.  
Includes **Adioscope (journaling)** and **Vision Planner**, supported by **AI-driven recommendations**.  
*Stack:* Node.js • TypeScript • PostgreSQL • Ionic (Angular) • AWS S3 & CloudFront • Stripe
